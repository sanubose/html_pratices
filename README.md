# 🧪 How to Run

## HTML & CSS

Open any `.html` file directly in a browser.

For development, **VS Code + Live Server** can be used.

Example:

```bash
Live Server → Open index.html
```

---

## JavaScript

JavaScript files can be executed using a browser or Node.js depending on the file.

For Node.js:

```bash
node filename.js
```

For an ES Module:

```bash
node index.mjs
```
